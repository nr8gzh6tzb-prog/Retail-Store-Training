# Training site
1. Paste video links into `config.js` (VIDEOS 1–3). YouTube, Vimeo, or MP4.
2. Paste your Formspree endpoint into `FORMSPREE_URL` in `config.js`.
3. Set `TEST_MODE = false` before going live.
4. Upload all files to any static host (Netlify, GitHub Pages).
Progress is stored in the viewer's browser (localStorage).
